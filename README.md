# AVBox 测试版本更新记录

**当前测试版本：1.4.0.2**（versionCode：37）

## 2026-11-20 直播亮度与音量手势恢复
- 修复 `ComposeLiveController` 手势播放状态判断：原控制器的 `videoView` 从未绑定，导致手势始终可能被判定为不可用；现在直接维护播放器回调提供的 `PlayState`。
- 上下滑方向识别改为累计位移超过系统 touch slop 后再锁定，减少起始横向抖动造成的误判；仍按手势起点相对播放器控制器宽度的左右半区区分左侧亮度、右侧音量。
- 保留系统边缘区域避让、用户手势禁用开关及原有左右快滑切台逻辑。
- 仅完成远程源码修改和静态内容核对，未运行 Gradle 构建、自动化测试或真机验证。

## 2026-11-20 直播选台列表对比度与旋转生命周期加固
- 平板横屏频道抽屉中的分组标题、频道号和频道名称统一为白色字形并叠加黑色描边，增强亮/暗视频背景上的辨识度。
- 抽屉背景加强磨砂效果：播放器底层高斯模糊由 18dp 提升至 30dp，列表面板使用更明显的半透明深色底；模糊作用于整个全屏播放器底层，列表面板完整覆盖其上。
- LivePlayActivity 仅在真正结束且非配置变化时调用 `PlaybackService.exitLive()`；非 finishing 的 Activity 销毁不再主动终止共享直播会话，补充 onStop / onPause / 配置变化日志。
- LivePlayActivity 的配置变化声明补充 `uiMode|colorMode`。
- 旋转重启问题尚不能宣称已彻底修复：代码已增加会话保护和生命周期诊断，但仍需在用户设备验证；若进程 PID 变化或发生崩溃，需结合 Logcat 确认根因。
- 仅完成远程源码修改，未运行 Gradle 构建、自动化测试或真机验证，未生成 APK。

## 2026-11-20 内置点播源调整（源码更新，未构建）
- 点播内置项收敛为单一多仓接口：`https://gh-proxy.com/https://raw.githubusercontent.com/niubihu1/tvbox/main/自用仓库.txt`；该文件包含 22 个候选仓库入口，由远端维护。
- 内置目录版本升至 3；从旧目录版本升级时清理此前仓库预置的 16 个旧点播地址及上一版 10 个点播地址，再添加该多仓接口。用户自行添加的其他点播订阅不主动删除。
- 保留现有 `Clun IPTV 直播` 内置源，并保留用户已有直播订阅。
- 已读取远端配置并确认其 `urls` 数组包含 22 项；AVBox 的配置解析器支持此类多仓接口格式。未逐个验证 22 个下游源的可用性。


## 1.4.0.2（2026-11-19）
- 内置点播源替换为 `audit/repair-sources-2026-11` 分支的 10 个配置（小洒、JSM、JS、饭太硬、电视、0827、367、0826、0825、0821）；首次启动及目录升级时自动合并，升级时移除上一版仓库内置点播源，保留用户自行添加的其他订阅与直播订阅。
- 已检查 10 个远端配置均可读取且为合法 JSON，`sites` 数量分别为 117、163、297、49、164、33、106、54、135、86；这仅代表配置结构可解析，不代表所有站点接口和播放地址均已实测可用。
- 直播旋转排查：记录 Activity 创建、销毁、配置变化和进程 PID；配置变化触发 Activity 重建时保留共享直播会话，避免主动退出直播。
- 平板横屏频道抽屉改为半透明磨砂面板，列表打开时模糊视频背景，文字保持清晰不透明。

- 直播页统一管理屏幕方向，避免基础页面方向策略与直播页横屏控制相互覆盖。
- 普通播放状态跟随设备传感器，全屏状态锁定横屏；本次待构建与真机验证。
- 修正直播页上下滑手势区域识别：按手势起始位置区分左侧亮度与右侧音量，避免拖动过程中跨区误切换。

## 1.4.0.1（2026-11-19）

- 直播页独立接管屏幕方向：普通状态跟随设备传感器，全屏状态才锁定横屏，基础页面方向策略不再干预直播页。
- 保留既有横屏沉浸式状态栏与播放器状态管理逻辑。

## 1.4.0（2026-11-19）

- 优化平板横屏直播播放界面：频道抽屉、沉浸式状态栏与频道信息显示逻辑。
- 首次启动时补充内置订阅：16 个点播配置和 1 个 IPTV 直播源；18+ 源单独标注。
- 内置源采用增量合并和 URL 去重，不覆盖用户已有订阅。
- APK 测试工作流改为手动触发，普通代码提交不自动构建 APK。

> **测试状态：** 本次仅更新代码与版本记录，尚未完成 Gradle 编译和真机验证；未生成 APK，未发布 Release。
