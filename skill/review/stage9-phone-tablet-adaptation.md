# 第九阶段：手机、平板适配审查

## 第一轮：设置与配置页面宽屏内容约束

### 审查范围
- `ui/WindowSize.kt` 与 `WindowSizeTest.kt`
- 首页网格、分类二级页网格、搜索结果布局
- 详情页内容流与 Hero 布局
- 设置主页、偏好设置、播放设置、主题设置、配置管理页
- `skill/avbox-mobile-ui-spec.md` 的窗口分档与页面规范

### 现状确认
- `WindowSize` 已按 600dp / 840dp 划分 Compact、Medium、Expanded；手机方向锁定依据 `smallestScreenWidthDp`，大屏不锁方向。
- 首页与分类网格已根据可用宽度动态计算列数；搜索结果的横向分栏已有列数上限。
- 详情内容流已有 1200dp 最大宽度并居中，Hero 背景与全屏层不受限制。
- 设置主页、偏好设置、播放设置、主题设置和配置管理页的主体内容列原先随窗口宽度无限扩张，平板横屏下表单和设置卡片的阅读跨度过大。

### 调整
- 在 `WindowSize` 增加统一内容宽度常量 840dp。
- 五个设置/配置页面的主体内容列统一顶部居中并限制最大宽度 840dp；窗口小于该宽度时仍按可用宽度铺满。
- 顶栏、弹层、播放器、直播画面及详情页全屏 Hero 不受此限制。
- 将约束写入移动端 UI 规范 §4.13。

## 第二轮：直播横屏主分类/子频道双栏列表

### 需求与现状
- 用户要求横屏直播列表增加二级列表，便于先选主分类再选子分类。
- 原平板横屏抽屉沿用单列可折叠分组：主分类与其频道混排在同一列表，分类较多时需要反复展开/折叠，定位子频道不够直接。

### 调整
- 横屏抽屉改为双栏：左侧主分类，右侧当前分类的子频道。
- 主分类点击复用 Activity 既有 `selectChannelGroup(groupIndex, -1)`，保留密码校验与按需展开；右侧只呈现当前分类的频道。
- 子频道点击仍复用 `selectChannel(groupIndex, position)`，播放成功后按既有逻辑关闭抽屉。
- 当前频道高亮与滚动定位仍读取 ViewModel 状态，不引入 Activity 非观察字段；锁定分组右侧提示需密码。
- 手机及平板竖屏继续使用原单列折叠列表。
