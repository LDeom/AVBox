# AVBox 全功能操作日志覆盖计划与实施记录

## 目标
把用户可见功能的关键操作、异步任务结果、异常和取消行为纳入统一运行日志，供后续复现、定位和修复问题。日志是诊断辅助，不等同于完整网络抓包或用户行为分析。

## 统一事件格式
- 使用 `AppLog.newOperationId()` 为一次操作分配进程内递增 ID。
- 使用 `AppLog.operationEvent(id, feature, phase, detail)` 记录阶段。
- feature 使用稳定模块标识；phase 使用 start、attempt、success、empty、failure、cancel、cleared 等有限状态。
- 不记录搜索词、播放完整 URL、Cookie、Authorization、Token、密码、验证码、二维码内容或原始请求/响应正文。
- URL 查询串继续由统一脱敏器处理；新增字段仍须遵循最小化原则。
- 文件日志遵循现有用户开关；关闭时不写入文件，Debug Logcat 行为仍由现有实现控制。

## 本轮源码修改
- `AppLog` 增加统一 operation ID 与结构化事件入口，并将 `event:` 纳入现有文件日志白名单。
- `SourceViewModel` 的分类、列表、详情、搜索、播放解析、预加载、Spider action、取消和 ViewModel 清理入口增加事件记录。
- 搜索只记录关键词长度，不记录关键词内容；播放只记录 URL 是否存在，不记录播放地址。
- JS 弹幕插件记录启用插件数量、插件尝试、成功、空结果和异常类型，不记录视频标题、集数或弹幕正文。

## 覆盖清单（需要继续逐模块补齐）
1. 启动与生命周期：启动、恢复、退出、旋转、前后台切换、Activity/Service 生命周期。
2. 配置中心：订阅新增/编辑/删除/启用/禁用、点播/直播源切换、TXT 多仓解析、配置拉取/缓存/解析/应用、TMDB 设置与测试。
3. 首页与内容：推荐、分类、翻页、筛选、刷新、搜索、详情、收藏、历史、追更。
4. 播放器：播放请求、解析、线路/播放器切换、重试、缓冲、错误、字幕、音轨、画面参数、投屏、播放进度与退出。
5. 直播：源加载、分组/频道切换、EPG、回看、代理、手势、音量/亮度、横竖屏。
6. 插件与脚本：JS/JAR/Python 加载、初始化、方法调用、超时、取消、兼容性失败。
7. 云盘与浏览器：网页登录导航/进度/HTTP/JS 错误、Cookie 读取/保存/清理/注入决策、provider/domain 匹配结果（不记录 Cookie）。
8. 网络与缓存：请求类别、目标 host、状态码、耗时、重试、缓存命中/未命中/淘汰；不记录完整 URL query 和正文。
9. 设置与交互：设置项变更、日志开关、日志导出、主题/语言/布局/手势配置。
10. 系统能力：权限、文件选择、下载、导入导出、DLNA、外部授权回调。

## 后续实施规则
- 逐模块在真实业务入口和最终回调处补充 start/success/empty/failure/cancel 事件，避免只记录按钮点击而没有结果。
- 对高频事件（播放进度、网络分片、滚动帧、音量连续变化）只记录状态变化摘要或采样，禁止逐帧刷日志。
- 为每个阶段补充单元测试，验证事件脱敏、开关行为和操作关联 ID。
- 不以日志覆盖率为由记录个人内容或凭据；导出前再次脱敏。
- 当前仅完成首轮公共入口与插件日志接入，不能宣称所有功能已全部覆盖。

## 第二轮源码接入
- 配置中心：TMDB 开关/海报样式/API Key 是否填写/API 测试、订阅源添加/编辑/删除/切换、直播跟随点播等入口增加操作事件。仅记录是否填写及模式，不记录 API Key 和订阅 URL。
- 首页：刷新、源切换、订阅切换、分类/列表加载、重试、筛选、收藏和视频操作入口增加事件。
- 详情页：播放请求、重试、源/集切换、线路选择、收藏、倒序、画质选择及全屏切换入口增加事件。
- 直播：全屏、方向、OSD、频道抽屉、频道/分组选择和设置项操作入口增加事件；未找到的动作委托接口未强行插入。
- 云盘内置浏览器：导航开始/完成、主框架资源错误和 HTTP 错误记录 provider、host、错误码/状态码；不记录完整 URL、Cookie 或页面内容。
- 本轮这些入口事件以操作开始/状态为主；异步最终结果仍需逐个补充，且需要通过运行日志回归验证实际落盘情况。


## 第三轮：异步结果与日志设置
- 分类和列表请求在当前请求仍有效时记录结果是否为空，并沿用请求开始时的 operation ID，形成入口到结果的关联。
- 日志开关和日志导出动作增加事件；开关关闭后文件日志自然停止记录，关闭动作只能在关闭前已写出的日志中体现，不能承诺关闭后仍写入文件。
- 事件详情过滤控制字符，降低用户自定义源标识造成日志换行注入的风险。
